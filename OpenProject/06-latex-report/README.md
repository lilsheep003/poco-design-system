# LaTeX Report Project

This folder contains a standalone LaTeX version of the RECS toolkit report.

## Files

- `main.tex` - report source
- `references.bib` - BibTeX bibliography

## Compile on Overleaf

1. Create a new Overleaf project.
2. Upload `main.tex` and `references.bib`.
3. Set `main.tex` as the main document.
4. Compile with `pdfLaTeX`.

## About the requested template

The provided Overleaf project link returned a private/forbidden page from this environment, so the template files could not be downloaded directly. This project uses a clean report-style LaTeX structure that can be pasted into the requested template later.

If you export the Overleaf template as a `.zip`, replace the template's body content with the chapters from `main.tex` and keep `references.bib`.
